Tileworlds

Playable right here, without sound. Open it full screen for sound.

Four mobile puzzle games on Tileworks, a modular Unity framework I wrote on my own time to show how I design and write gameplay code. It is not a shipped product: no players, no metrics, and the art is AI-generated placeholder work.

  • Rules you can test without the engine. One deterministic rules engine runs Tile Match, Block Puzzle, Blast and Gem Swap.
  • Levels generated and measured, never guessed. A solver and bots play every level until it lands on its target win rate.
  • Rules run ahead, the view catches up. You can keep playing while pieces are still falling.
  • One transaction per level result. SQLite saves with DAOs, migrations, backup and restore.
  • Architecture rules as tests. About 940 test cases in all.
